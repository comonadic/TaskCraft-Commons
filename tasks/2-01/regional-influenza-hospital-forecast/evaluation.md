# 地区四周流感住院预测：评分方法

评分器读取交付文件，逐项计算 0～1 的得分，再按权重求加权平均。网站以 100 分制展示结果。

## 计算流程

1. 读取完整地点、周次与分位数预测，检查概率顺序和结果结构。
2. 用评分期真实值重算 WIS 与 MAE，并与 naive 基线比较。
3. 在新工作目录复跑提交代码，比较重新生成的预测。

## 指标与阈值

- 技能得分 = 0.7 × clip((1−WIS/基线WIS)/0.35,0,1) + 0.3 × clip((1−MAE/基线MAE)/0.35,0,1)。
- 预测技能占 90%，代码复跑一致性占 10%。
- 每份预测须恰好包含 212 个唯一地点与周次组合；区间须满足 0 ≤ lower95 ≤ point ≤ upper95。

## 检查项

| 检查项 | 权重 | 程序入口 |
|---|---:|---|
| 相对naive预测技能 | 90% | `skill` |
| 预测代码隔离复跑 | 10% | `rerun` |

## 业务规则

- **预测表现（90 分）**：分别计算相对朴素基线的 WIS 与 MAE 改进率，两者按 70% 和 30% 加权；改进率除以 35% 并截在 0～1 后计分。
- **结果复现（10 分）**：重新执行预测程序，将生成结果与提交表逐记录比较；方法说明至少 30 个字符。

## 分数与日志

`reward = Σ(weight × check_score) / Σ(weight)；网站得分 = 100 × reward`

缺少文件、解析失败或检查异常时，该检查项记 0 分，并在 score.json 中记录原因。

完整实现见 [grade.py](tests/grade.py) 与 [support.py](tests/support.py)。
