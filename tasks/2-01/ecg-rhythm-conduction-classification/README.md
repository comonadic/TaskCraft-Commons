# 12 导联心电心律与传导分类

利用 12 导联心电波形训练多标签模型，识别心律和传导类别，并整理预测结果与建模方法。

职业：医学研究人员（2-01-08-00）

[任务卡](task_card.json) · [任务说明](instruction.md)

## 工作场景

你负责心电信号研究分析，需要以训练集建立分类流程，并在测试波形上生成 13 类标签预测。

## 材料

800 条训练记录、2,263 条测试波形和 13 类标签定义；每条波形为 10 秒、100 Hz、12 导联。

## 评分方法

**分类效果 · 98 分**

按测试 ID 对齐预测与参考标签，计算宏平均 F1；本项得分为 98 × min(1, F1 ÷ 0.75)。

**方法说明 · 2 分**

读取方法报告，正文超过 60 个字符取得本项分数。

预测文件需完整覆盖测试 ID，每个 ID 唯一，标签列取值为 0 或 1。
