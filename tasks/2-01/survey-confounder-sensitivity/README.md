# 调查队列混杂敏感性分析

连接调查队列和用药事件数据，重建分析样本，并比较加入不同混杂因素后的关联估计。

职业：医学研究人员（2-01-08-00）

[任务卡](task_card.json) · [任务说明](instruction.md)

## 工作场景

你是医学研究分析人员，需要检验幽门螺杆菌与 NSAID 用药等因素对目标关联估计的影响。

## 材料

5,000 人的调查队列、用药事件和变量定义。

## 评分方法

**分析样本 · 40 分**

按个体 ID 比对病例集合和变量，按记录与字段的正确比例计分。

**模型结果 · 60 分**

按模型比对估计值、置信区间、P 值与变化比例，绝对容差为 0.00001。
