# 智能体平台插件数据政策审计

依据平台数据政策检查插件字段，汇总违规与严重程度，并分析不同业务域的数据暴露范围。

职业：企业合规师（2-06-07-14）

[任务卡](task_card.json) · [任务说明](instruction.md)

## 工作场景

你是企业合规人员，需要评估智能体与插件的数据使用是否符合给定政策。

## 材料

80 个智能体、160 个动作的接口字段、24 个业务域和平台政策。

## 评分方法

**字段违规 · 65 分**

按动作 ID 与字段名比对违规记录、条款和严重性，按正确比例计分。

**违规汇总 · 10 分**

比对违规总数和严重性分布，按字段正确比例计分。

**业务域暴露 · 25 分**

按业务域比较聚合人数、数据类型数量和放大率，按正确比例计分。
