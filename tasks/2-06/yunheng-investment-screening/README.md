# 云衡软件私募投资初筛备忘录

阅读云衡软件的公司、财务与客户资料，形成投资初筛建议，列出投资论点、风险和后续尽调问题。

职业：证券投资专业人员（2-06-11-03）

[任务卡](task_card.json) · [任务说明](instruction.md)

## 工作场景

你是投资研究人员，需要向团队提交一份结构完整、结论明确并能追溯资料的初筛备忘录。

## 材料

八份公司与经营资料，包含三年财务、客户队列、董事会与销售信息。

## 评分方法

**财务指标 · 45 分**

逐字段比对八项财务计算，按正确比例计分。

**论点与引文 · 15 分**

检查论点、风险和尽调项的引文是否对应资料文件及页码，按有效条目比例计分。

**风险识别 · 10 分**

四类风险 ID 集合按 F1 计分。

**尽调问题 · 10 分**

四项尽调 ID 集合按 F1 计分。

**备忘录与建议 · 20 分**

检查八章完整、建议枚举及报告与结构化建议一致，建议理由至少 20 字。
