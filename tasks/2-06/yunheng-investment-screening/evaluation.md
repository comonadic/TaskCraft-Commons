# 云衡软件私募投资初筛备忘录：评分方法

评分器读取交付文件，逐项计算 0～1 的得分，再按权重求加权平均。网站以 100 分制展示结果。

## 计算流程

1. 从 analysis.json 核对八项财务指标和论点证据。
2. 计算四类风险与四项待尽调事项的覆盖 F1。
3. 核对中文投资备忘录、明确建议与分析结构。

## 指标与阈值

- 财务计算 45%、论点证据 15%、风险 10%、待尽调 10%、备忘录 20%。
- 自动评分覆盖数值与文件结构；投资判断的专业质量可在审题时由领域贡献者补充评议。

## 检查项

| 检查项 | 权重 | 程序入口 |
|---|---:|---|
| 八项财务计算 | 45% | `lambda: tree_score(read_json(OUTPUT / 'analysis.json')['metrics'], read_json(TESTS / 'expected.json'))` |
| 论点与证据结构 | 15% | `evidence` |
| 四类风险覆盖 | 10% | `lambda: f1_set([x['id'] for x in read_json(OUTPUT / 'analysis.json')['risks']], ['R1', 'R2', 'R3', 'R4'])` |
| 四项待尽调 | 10% | `lambda: f1_set([x['id'] for x in read_json(OUTPUT / 'analysis.json')['diligence']], ['Q1', 'Q2', 'Q3', 'Q4'])` |
| 完整中文备忘录及明确建议 | 20% | `memo` |

## 业务规则

- **财务指标（45 分）**：逐字段比对八项财务计算，按正确比例计分。
- **论点与引文（15 分）**：检查论点、风险和尽调项的引文是否对应资料文件及页码，按有效条目比例计分。
- **风险识别（10 分）**：四类风险 ID 集合按 F1 计分。
- **尽调问题（10 分）**：四项尽调 ID 集合按 F1 计分。
- **备忘录与建议（20 分）**：检查八章完整、建议枚举及报告与结构化建议一致，建议理由至少 20 字。

## 分数与日志

`reward = Σ(weight × check_score) / Σ(weight)；网站得分 = 100 × reward`

缺少文件、解析失败或检查异常时，该检查项记 0 分，并在 score.json 中记录原因。

完整实现见 [grade.py](tests/grade.py) 与 [support.py](tests/support.py)。
