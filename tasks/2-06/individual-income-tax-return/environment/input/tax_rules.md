# 2024限定练习规则
应纳税所得额=max(0,全年工资收入-60000-专项扣除-已审核专项附加扣除)。应纳税额=应纳税所得额*税率-速算扣除数。补退税balance=应纳税额-已预缴，负数表示退税。金额四舍五入2位，月表累加后再舍入。
上限/税率/速算扣除数：36000/.03/0；144000/.10/2520；300000/.20/16920；420000/.25/31920；660000/.30/52920；960000/.35/85920；超过960000/.45/181920。上限含等号。
税率与6万元扣除依据：国家税务总局《中华人民共和国个人所得税法》 https://www.chinatax.gov.cn/n810219/n810744/n3752930/n3752974/c3970366/content.html
