# 中国股票市场五因子月度重建

依据股票行情与财报披露时间构建五因子月度序列，整理投资组合计算结果和样本筛选记录。

职业：证券投资专业人员（2-06-11-03）

[任务卡](task_card.json) · [任务说明](instruction.md)

## 工作场景

你是资产定价研究人员，需要从原始市场和财务数据构建可追踪的五因子序列。

## 材料

180 只股票的行情、财务与披露记录，以及无风险收益和计算规则。

## 评分方法

**五因子序列 · 90 分**

按月份比对全部五因子数值及月份集合，绝对容差为 0.00001，按正确比例计分。

**样本审计 · 10 分**

按月份比对合格样本数与迟到披露剔除数，按正确比例计分。
