# 澄海精密 2024 年合并资产负债表重构

阅读澄海精密年度报告，整理报告期末的合并资产负债表，并为各项金额提供可定位的报告依据。

职业：会计专业人员（2-06-03-00）

[任务卡](task_card.json) · [任务说明](instruction.md)

## 工作场景

你负责为财务分析团队整理澄海精密的年度财务数据。报告同时列有合并报表、母公司报表和上年比较数，需要将目标期间的数据整理为统一口径。

## 材料

提供年度报告的 PDF 与 HTML 两种阅读格式，以及报表字段说明。

## 评分方法

**金额与报表信息 · 80 分**

逐字段比对报告期、币种、单位及金额。金额采用 0.01 元绝对容差，并结合相对容差 0.001%；本项按正确字段比例计分。

**报告依据 · 20 分**

比对每个字段的文件、页码与原文摘录，按证据字段的正确比例计分。
