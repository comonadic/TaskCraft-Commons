# 订单应用 Compose 到 Kubernetes 迁移

将订单应用迁移到 Kubernetes，完成 Helm 部署、基础设施和流水线配置，并检查服务运行与网络访问。

职业：云计算工程技术人员（2-02-38-04）

[任务卡](task_card.json) · [任务说明](instruction.md)

## 工作场景

你是云平台工程师，需要迁移包含 React 前端、Flask 后端和 PostgreSQL 数据库的订单应用。

## 材料

订单应用源码、Compose 配置、部署要求和任务集群。

## 评分方法

**部署配置 · 70 分**

资源覆盖 20 分、资源配置 25 分、Terraform 10 分、五阶段流水线 10 分、运行记录和中文报告 5 分；各项按满足要求的比例计分。

**集群运行 · 30 分**

Pod 可用性 12 分；Service、接口与数据库、HPA 指标、网络连接各 4.5 分，按实际集群检查结果计分。

先检查 Chart 渲染、values 文件及 Secret 编码，满足这些条件后计算各项得分。
