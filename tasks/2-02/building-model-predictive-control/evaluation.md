# 建筑节费与削峰模型预测控制：评分方法

评分器读取交付文件，逐项计算 0～1 的得分，再按权重求加权平均。网站以 100 分制展示结果。

## 计算流程

1. 使用 BuildingRC 动力学独立回放提交控制量，重算室温、用电与舒适度。
2. 与固定基线比较电费和峰值负荷，核对模型识别系数。
3. 在新目录复跑控制器并检查诊断产物。

## 指标与阈值

- 动力学与指标 60%、节费与削峰 25%、模型识别 10%、控制器复跑和诊断 5%。
- 模型系数绝对容差 1e−6；动力学、性能归一化与舒适度阈值见对应 dynamics、performance 函数。

## 检查项

| 检查项 | 权重 | 程序入口 |
|---|---:|---|
| 独立动力学回放与指标重算 | 60% | `dynamics` |
| 节费与削峰 | 25% | `performance` |
| RC模型识别 | 10% | `lambda: tree_score(read_json(OUTPUT / 'identified_model.json'), {'air_coefficients': [0.9, 0.05, 0.05, 0.0012, 0.12, -0.28], 'wall_coefficients': [0.02, 0.97, 0.01, 0, 0, 0]}, atol=1e-06)` |
| 控制器隔离复跑与诊断 | 5% | `rerun` |

## 业务规则

- **温度与指标（60 分）**：独立执行 672 步动力学，逐步比对温度、动作及指标；数值绝对容差为 0.00001，并检查舒适度约束。
- **节费与削峰（25 分）**：费用与峰值改进各占本项一半；相对基线改进达到 1% 时该半项满分，较低改进按比例计分。
- **模型辨识（10 分）**：比对模型系数，绝对容差为 0.000001。
- **程序复现与诊断（5 分）**：训练 RMSE 小于 0.00001，并重新执行控制器、比对指标结果。

## 分数与日志

`reward = Σ(weight × check_score) / Σ(weight)；网站得分 = 100 × reward`

缺少文件、解析失败或检查异常时，该检查项记 0 分，并在 score.json 中记录原因。

完整实现见 [grade.py](tests/grade.py) 与 [support.py](tests/support.py)。
