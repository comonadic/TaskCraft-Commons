# 建筑节费与削峰模型预测控制

识别建筑热力模型，分别设计节费与削峰控制策略，比较能耗表现并保持占用期间的舒适度。

职业：自动控制工程技术人员（2-02-07-07）

[任务卡](task_card.json) · [任务说明](instruction.md)

## 工作场景

你是建筑控制工程师，需要在 15 分钟控制周期下比较基线、节费和削峰三种策略。

## 材料

480 步辨识数据、672 步天气与电价数据，以及建筑热力与舒适度规则。

## 评分方法

**温度与指标 · 60 分**

独立执行 672 步动力学，逐步比对温度、动作及指标；数值绝对容差为 0.00001，并检查舒适度约束。

**节费与削峰 · 25 分**

费用与峰值改进各占本项一半；相对基线改进达到 1% 时该半项满分，较低改进按比例计分。

**模型辨识 · 10 分**

比对模型系数，绝对容差为 0.000001。

**程序复现与诊断 · 5 分**

训练 RMSE 小于 0.00001，并重新执行控制器、比对指标结果。
