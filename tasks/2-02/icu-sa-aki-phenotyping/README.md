# 医院多系统事件表 SA-AKI 表型提取

连接 ICU 住院与临床事件记录，按时间窗识别 SA-AKI 表型，交付患者名单和逐住院判定记录。

职业：数据分析处理工程技术人员（2-02-30-09）

[任务卡](task_card.json) · [任务说明](instruction.md)

## 工作场景

你是医学数据分析人员，需要将分散在不同系统的事件整理为一致的住院时间线和表型结果。

## 材料

600 人的 ICU 住院、感染、SOFA、肌酐与尿量事件表和判定规则。

## 评分方法

**患者名单 · 65 分**

与参考患者集合计算 F1，按 65 × F1 计分；患者 ID 唯一且列名为 subject_id。

**时间线与判定 · 35 分**

按住院 ID 比对起始时间、资格和理由，按记录与字段正确比例计分。
