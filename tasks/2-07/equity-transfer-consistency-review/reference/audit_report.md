# 股权转让一致性审计

四份合成公告交叉核对。

## 发现1：amount
同一交易存在互不相容的陈述：24000万元 与 2.6亿元。
- [A.pdf:p1] 本次交易对价为人民币24000万元。
- [B.pdf:p1] 本次交易对价为人民币2.6亿元。

## 发现2：ownership
同一交易存在互不相容的陈述：30% 与 35%。
- [A.pdf:p1] 受让方拟取得标的公司30%股权。
- [C.pdf:p1] 权益变动完成后青岚产业持股比例为35%。

## 发现3：share_count
同一交易存在互不相容的陈述：3000万股 与 3200万股。
- [A.pdf:p2] 转让股数为3000万股，每股价格8元。
- [D.pdf:p1] 受让股数为3200万股。

## 发现4：approval_date
同一交易存在互不相容的陈述：2024年11月18日 与 2024年11月19日。
- [A.pdf:p2] 董事会审议日期为2024年11月18日。
- [D.pdf:p2] 董事会审议日期为2024年11月19日。

## 核对说明
员工数截止日不同且新增人数可调节；净资产显示为四舍五入；30日付款描述一致，均不作为错误发现。
