# 厂房与塔楼图纸三维重建

根据建筑平面、立面和剖面图重建厂房与塔楼，整理构件名称与尺寸，并交付可继续编辑的三维模型。

职业：建筑信息模型技术员（4-08-08-23）

[任务卡](task_card.json) · [任务说明](instruction.md)

## 工作场景

你是建筑信息模型技术员，需要依据六张建筑图纸搭建包含大厅与塔楼的三维模型，供设计团队查看和后续使用。

## 材料

六张 PDF 建筑图纸，以及构件名称与尺寸说明。

## 评分方法

**原生模型 · 50 分**

检查毫米单位和闭合构件；按构件名称比对位置与尺寸，允许 1 mm 绝对误差，按正确构件比例计分。

**OBJ 模型 · 50 分**

检查顶点、闭合实体与构件名称，并按位置和尺寸正确的构件比例计分；最少包含 1,000 个顶点。
