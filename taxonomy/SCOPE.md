# 知识工作职业范围

TaskCraft 收录可以通过数字材料、电脑软件和业务系统完成的专业任务：研究与分析、金融会计、法律合规、医学与药学、科学教育、编程、数字设计、文档处理及业务软件操作。

职业分类采用中国职业编码。一个职业可以同时包含现场职责，贡献到本站的任务应聚焦可在数字环境中完成的工作环节，例如采矿工程师的方案分析、工业视觉运维员的配置诊断，或医生的研究数据分析。现场采矿工、搬运与体力生产岗位，以及政府、军队和政治职责不在本站范围中。

## 层级与数据

- `china_occupations.json`：站内知识工作目录，领域 → 具体职业。
- `scope-policy.json`：收录前缀、单独收录与排除规则；排除优先。
- `china_occupations.full.json`：原始职业分类资料，保留供维护与查找编码使用。

## 扩充目录

1. 从原始职业分类资料中找到稳定职业编码。
2. 提供一项典型的数字工作流程，例如 CAD 图纸修订、药物研究文献分析、会计软件核算或课堂作业设计。
3. 明确输入材料、使用的软件、交付文件和可核对的结果。
4. 将职业编码加入 `includeCodes`。整个职业族均适用时，才加入 `includePrefixes`。
5. 更新站内目录与网站数据；保留“领域 → 具体职业”的层级和中国职业编码。

领域显示名称为知识工作场景整理，原分类名称保留在 `classificationName`。当前上游版本为《职业分类大典》2022 年社会公示稿。
